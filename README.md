# مقياسي — منصة المقاييس النفسية

منصة ويب (كمبيوتر وجوال) يجري فيها المستخدم المقياس بنفسه، وتظهر له النتيجة، ونصيحة بمراجعة المختص حسب الدرجة، وخطة دعم، وتقرير قابل للطباعة. الواجهة تتغير حسب العمر: كرتونية للأطفال (8–12)، عصرية للمراهقين (13–17)، هادئة للراشدين.

## الملفات
- `index.html` الصفحة · `css/style.css` التصميم
- `js/config.js` إعدادات Appwrite (الملف الوحيد الذي تعدّله للربط)
- `js/scales.js` المقاييس ومفاتيح التصحيح · `js/plans.js` النصائح وخطط الدعم
- `js/store.js` الحسابات وحفظ النتائج · `js/app.js` الواجهة

## المقاييس (14)
SCARED، PHQ-9، GAD-7، DASS-21، WHO-5، PSS-10، روزنبرغ، MSPSS، SWLS، GSE، BRS، PCL-5، EPDS، GDS-15.

## قبل النشر الفعلي
1. **نصوص البنود:** الصياغة العربية في `scales.js` ترجمة عمل. استبدلها بالنسخة العربية الرسمية المقننة لكل مقياس (المصدر مذكور في حقل `source`).
2. **التراخيص:** PSS-10 مجاني للاستخدام التعليمي والبحثي غير الربحي فقط؛ راجع شروط كل مقياس إذا كان الاستخدام تجارياً.
3. **نص الطوارئ:** ضع في `urgentHelp` داخل `config.js` أرقام الجهات المعتمدة لديك.
4. **مراجعة مختص:** اعرض مفاتيح التصحيح والخطط على أخصائي نفسي قبل الإتاحة للطلاب.

## ربط Appwrite
1. أنشئ مشروعاً، ثم من Overview → Add platform → Web أضف اسم النطاق (مثل `waeljakson.github.io`).
2. Auth → Settings: فعّل Email/Password.
3. Databases: أنشئ قاعدة بيانات TablesDB وجدولاً (Table) بالمعرّف `results`، وضع معرّف القاعدة في `databaseId` داخل `js/config.js`.
4. في إعدادات الجدول: Permissions → أضف الدور `Users` بصلاحية Create فقط، وفعّل **Document security**.
5. أضف الأعمدة (Attributes):

| المفتاح | النوع | ملاحظات |
| --- | --- | --- |
| scaleId | String 32 | مطلوب |
| scaleName | String 100 | مطلوب |
| total | Float | مطلوب |
| max | Float | مطلوب |
| band | String 300 | مطلوب |
| level | Integer | مطلوب |
| urgent | Boolean | مطلوب |
| subs | String 3000 | |
| answers | String 1000 | |
| age | Integer | |
| gender | String 1 | |

6. ضع الـ Endpoint والـ Project ID في `js/config.js`.

كل نتيجة تُحفظ بصلاحية قراءة وحذف لصاحبها فقط. العمر والجنس وموافقة ولي الأمر تُحفظ في تفضيلات الحساب.

## النشر على GitHub Pages
Settings → Pages → Source: Deploy from a branch → `main` / root.

## الوضع التجريبي
إذا تُرك `projectId` فارغاً تعمل المنصة بلا خادم وتحفظ على الجهاز فقط (للتجربة).

## لوحة الإدارة
- المدير هو أي حساب يحمل الوسم `admin` في Appwrite (Auth ← المستخدم ← Labels). لا توجد كلمة مرور للمدير داخل الكود.
- الجداول: `results` (النتائج)، `profiles` (بيانات المستخدمين للإدارة)، `blocks` (الحسابات الموقوفة).
- الصلاحيات يفرضها Appwrite: المستخدم يقرأ صفوفه فقط، وحامل الوسم `admin` يقرأ ويحذف الكل.
- الإيقاف يمنع الدخول من المنصة. الحذف النهائي للحساب أو إعادة تعيين كلمة المرور يتم من لوحة Appwrite ← Auth.

## إضافات النسخة الثانية
- استعادة كلمة المرور بالبريد (تعتمد على `siteUrl` في `js/config.js`).
- حفظ التقدم داخل المقياس على الجهاز، والمتابعة لاحقاً.
- التقرير الشامل ورسم تطور النتائج.
- صفحة الخصوصية.
- ملاحظات المتابعة للمدير (جدول `notes`، صلاحياته للوسم `admin` فقط).

## النسخة الثالثة: السجل الأسري والرسوم
- **أسرتي:** صاحب الحساب يضيف أبناءه أو زوجه (جدول `members`)، ويختار الفرد من أعلى الصفحة الرئيسية لإجراء المقياس له. النتائج تُحفظ باسم الفرد (`memberId`، `memberName`).
- **تقرير الحالة النفسية للأسرة:** آخر نتيجة لكل فرد، مع نصائح لرب الأسرة.
- **نسخة ولي الأمر من SCARED** (`scared_p`): يجيب الوالد عن طفله (8–17 سنة).
- **واجهة الأطفال:** مشهد رحلة متحرك، صورة لكل سؤال، ووجوه كرتونية للإجابات.
- الفرد البالغ يجيب عن مقياسه بنفسه وبعلمه؛ لا تُجرى مقاييس التقرير الذاتي نيابةً عن أحد.

## النسخة الرابعة: مقاييس جديدة وتنسيق
أضيفت ستة مقاييس (المجموع 21): إدمان الألعاب الإلكترونية (IGDS9-SF)، إدمان الهاتف (SAS-SV)، وسائل التواصل (BSMAS)، الضيق النفسي (K10)، مزاج الأطفال (SMFQ)، وقائمة أعراض الأطفال لولي الأمر (PSC-17، من 4 سنوات).
الصفحة الرئيسية مقسمة إلى: المشاعر والمزاج، العادات الرقمية، العافية والقوة النفسية.
تراخيص: IGDS9-SF وSMFQ وBSMAS مجانية للاستخدام غير التجاري؛ راجع شروطها إن تغيّر نوع الاستخدام.

## النسخة السادسة: المستوى الإكلينيكي
- **استمارة تاريخ الحالة** لكل فرد (جدول `intakes`): الشكوى، المدة، البداية، التأثر الوظيفي، الضغوط، التاريخ العلاجي والأسري.
- **تقرير الفرز النفسي الأولي والإحالة** (`js/clinical.js`): بيانات تعريفية، تاريخ الحالة، جدول الأدوات بالدرجات والحدود الفاصلة وصلاحية الاستجابة، تحليل تفصيلي بالبنود الأعلى استجابة، مؤشرات الخطورة، انطباع أولي، مجالات يُقترح تقييمها، مستوى الإحالة والمختص المقترح، حدود التقرير، وخانة للمختص.
- **نموذج إكلينيكي** لتطبيق المقياس لمن عمره 16 فأكثر ولنسخ ولي الأمر: كل البنود في صفحة واحدة مع التحقق من اكتمالها. يُحفظ زمن الإنجاز (`secs`).
- التقرير نتيجة فرز وليس تشخيصاً؛ محتوى `clinical.js` يحتاج مراجعة مختص قبل الاعتماد.

## النسخة السابعة: توسيع المقاييس
أضيفت سبعة مقاييس (المجموع 28): SNAP-IV-18 (ولي الأمر)، ASRS-v1.1 (6 بنود)، قلق الاختبار (Westside)، OCI-R، PHQ-15، الوحدة (UCLA-3)، المثابرة (Grit-S). وقسم جديد "الانتباه والدراسة".
صفحة "اختبارات يطبقها المختص فقط" تعرّف بستانفورد-بينيه ووكسلر وغيرها دون بنودها: هذه اختبارات مرخّصة وفردية ولا يجوز نشرها.

## النسخة الثامنة: الاشتراك
- **النسخة المجانية:** `freeLimit` في `js/config.js` (افتراضياً مقياسان)، وكل مقياس مرة واحدة للشخص.
- **الاشتراك:** المستخدم يرسل طلباً من صفحة "الاشتراك" (طريقة الدفع، اسم المحوِّل، رقم العملية، صورة الإثبات) إلى جدول `payreq`. المدير يفعّل من لوحة الإدارة فيُكتب صف في `subs` صالح 30 يوماً لكل شهر.
- **بيانات الدفع:** يعدّلها المدير من لوحة الإدارة ← "بيانات الدفع" وتُحفظ في `settings` (يقرؤها المسجلون فقط). رقم الحساب والآيبان وصور QR لا تُكتب في الكود لأن المستودع عام.
- **حدود الحماية:** القيد المجاني مطبّق في الواجهة فقط. المنع الفعلي على مستوى الخادم يحتاج Appwrite Function.
- **التراخيص عند الاستخدام المدفوع:** PHQ-9، GAD-7، PHQ-15، PHQ-4، DASS-21، PCL-5، GDS-15، CES-D، CES-DC، SNAP-IV ملكية عامة. المقاييس التالية مجانية للاستخدام غير التجاري أو تحتاج إذناً، فيلزم إذن أصحابها قبل بيع الوصول إليها أو إضافتها إلى `disabledScales`: `pss10, who5, igds9, smfq, bsmas, grit, asrs6, ocir, scared, scared_p, epds, wtas`. راجع شروط الباقي أيضاً.
- مقاييس جديدة: PHQ-4، CES-D، CES-DC (المجموع 31).

## دالة الخادم saveResult
- الكود في `functions/saveResult/index.js` (Node 22، بلا اعتماديات). تُنشر في Appwrite ← Functions بالمعرّف `saveResult`، صلاحية التنفيذ `users`، والنطاقات `users.read, rows.read, rows.write`.
- تحفظ النتيجة بهوية المستخدم المسجّل بعد التحقق: مدير أو مشترك فعّال → حفظ بلا حد؛ غير ذلك → مقياسان فقط وكل مقياس مرة واحدة للشخص.
- جدول `results` لا يقبل الإنشاء من المتصفح؛ الإنشاء من الدالة فقط. المستخدم المجاني لا يملك صلاحية حذف نتائجه (حتى لا يستعيد رصيده بالحذف).
- عند تغيير الحد المجاني عدّل `FREE_LIMIT` في الدالة و`freeLimit` في `js/config.js` معاً وأعد نشر الدالة.
