# مقياسي — منصة المقاييس النفسية

منصة ويب (كمبيوتر وجوال) يجري فيها المستخدم المقياس بنفسه، وتظهر له النتيجة، ونصيحة بمراجعة المختص حسب الدرجة، وخطة دعم، وتقرير قابل للطباعة. الواجهة تتغير حسب العمر: كرتونية للأطفال (8–12)، عصرية للمراهقين (13–17)، هادئة للراشدين.

## الملفات
- `index.html` الصفحة · `css/style.css` التصميم
- `js/config.js` إعدادات Appwrite (الملف الوحيد الذي تعدّله للربط)
- `js/scales.js` المقاييس ومفاتيح التصحيح · `js/plans.js` النصائح وخطط الدعم
- `js/store.js` الحسابات وحفظ النتائج · `js/app.js` الواجهة

## المقاييس (14)
SCARED، PHQ-9، GAD-7، DASS-21، WHO-5، PSS-10، روزنبرغ، MSPSS، SWLS، GSE، BRS، PCL-5، EPDS، GDS-15.

## قبل النشر الفعلي
1. **نصوص البنود:** الصياغة العربية في `scales.js` ترجمة عمل. استبدلها بالنسخة العربية الرسمية المقننة لكل مقياس (المصدر مذكور في حقل `source`).
2. **التراخيص:** PSS-10 مجاني للاستخدام التعليمي والبحثي غير الربحي فقط؛ راجع شروط كل مقياس إذا كان الاستخدام تجارياً.
3. **نص الطوارئ:** ضع في `urgentHelp` داخل `config.js` أرقام الجهات المعتمدة لديك.
4. **مراجعة مختص:** اعرض مفاتيح التصحيح والخطط على أخصائي نفسي قبل الإتاحة للطلاب.

## ربط Appwrite
1. أنشئ مشروعاً، ثم من Overview → Add platform → Web أضف اسم النطاق (مثل `waeljakson.github.io`).
2. Auth → Settings: فعّل Email/Password.
3. Databases: أنشئ قاعدة بيانات بالمعرّف `nafsi` وجدولاً (Collection) بالمعرّف `results`.
4. في إعدادات الجدول: Permissions → أضف الدور `Users` بصلاحية Create فقط، وفعّل **Document security**.
5. أضف الأعمدة (Attributes):

| المفتاح | النوع | ملاحظات |
| --- | --- | --- |
| scaleId | String 32 | مطلوب |
| scaleName | String 100 | مطلوب |
| total | Float | مطلوب |
| max | Float | مطلوب |
| band | String 300 | مطلوب |
| level | Integer | مطلوب |
| urgent | Boolean | مطلوب |
| subs | String 3000 | |
| answers | String 1000 | |
| age | Integer | |
| gender | String 1 | |

6. ضع الـ Endpoint والـ Project ID في `js/config.js`.

كل نتيجة تُحفظ بصلاحية قراءة وحذف لصاحبها فقط. العمر والجنس وموافقة ولي الأمر تُحفظ في تفضيلات الحساب.

## النشر على GitHub Pages
